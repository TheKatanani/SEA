# منصة الأكاديمية السعودية للترفيه — SEA

موقع Next.js ثنائي اللغة (العربية والإنجليزية) مع أساس لوحة إدارة وربط Firebase وCloudinary. مسارات العربية الحالية هي الافتراضية، وتبدأ مسارات الإنجليزية بـ `/en`.

## التشغيل المحلي

```bash
npm install
npm run dev
```

افتح `http://localhost:3000`. لوحة الإدارة: `/admin`، والنسخة الإنجليزية: `/en/admin`.

## الصفحات والمحتوى

تشمل الصفحات الرئيسية، البرامج والدورات، القبول، التسجيل، المنشآت، الشركاء، الاعتماد، رحلة المتدرب، الأخبار، التقويم، المعرض، الأسئلة، الدعم والسياسات. تفاصيل المسارات ومصادر المحتوى موجودة في `CONTENT_STATUS.md` و`CONTENT_REQUESTS.md`.

الإنجليزية الحالية مسودة وليست ترجمة أكاديمية أو قانونية معتمدة. يجب اعتمادها قبل النشر. نموذج التسجيل يجمع طلب اهتمام وبيانات تواصل أولية فقط؛ لا يجمع رقم الهوية أو مستندات تعريفية، ولا ينشئ حساب طالب أو متابعة طلب في هذه المرحلة.

## ربط الخدمات

- متغيرات Firebase العامة المحلية موجودة في `.env.local` (هذا الملف مستثنى من Git). استخدم `.env.example` كقائمة للمتغيرات المطلوبة في بيئة الإنتاج.
- لا تضع مفتاح حساب الخدمة أو Cloudinary API Secret في متغير يبدأ بـ `NEXT_PUBLIC_` أو في ملفات الواجهة.
- يحتاج Firebase Authentication إلى تفعيل تسجيل الدخول بالبريد وكلمة المرور، وFirestore إلى إنشاء قاعدة البيانات وتطبيق `firestore.rules`.
- لا تعمل النماذج حتى تجهّز اعتماد Firebase Admin، ومفتاح تحديد المعدل، وتعتمد سياسة الخصوصية وتضبط `APPLICATIONS_ENABLED=true`.
- يتطلب رفع الملفات إعداد Cloudinary server secrets. يصدر الخادم توقيعًا قصير العمر بعد التحقق من صلاحية الموظف.
- Analytics غير مفعّل تلقائيًا؛ يوجد مدخل تهيئة لا يستدعيه التطبيق إلا بعد موافقة الزائر.

اقرأ [دليل إعداد وتشغيل الخدمات](./OPERATIONS.md) للتفاصيل وخطوات أول مدير.
